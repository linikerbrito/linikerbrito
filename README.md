# 👨🏻‍💻 Liniker Brito

**`Desenvolvedor Front-end`**

Me chamo Liniker Brito, sou natural de Mirandópolis, SP. Sou formado em Engenharia da Computação e tenho mais de 6 anos de experiência desenvolvendo aplicações web modernas.

Atualmente atuo como Desenvolvedor Front-end, construindo e mantendo aplicações corporativas com Vue.js, TypeScript, Quasar e APIs REST. Já passei por projetos que vão desde plataformas de e-commerce até sistemas corporativos internos, sempre com foco em interfaces intuitivas, performáticas e de fácil manutenção.

Trabalho principalmente com Vue.js (2 e 3), Nuxt.js, React, TypeScript, JavaScript, Tailwind CSS e Quasar, além de ter experiência com Vuetify, Pinia, Vuex, APIs REST, Docker, Azure DevOps e GitHub Copilot. Atualmente estou me aprofundando em Angular.
